# Generation specification

All sprites use the same Miko identity and wardrobe as the approved high-detail reference: tousled layered brown hair with looped cowlicks and orange star clip, amber eyes, cream tunic, olive shorts, mustard boots, and burnt-orange star cape. Each sprite is a full-body chibi illustration on a true transparent background, with clean anime rendering and no text, borders, scenery, furniture, or unrelated props.

- `01-settle-to-sleep`: compact kneeling/curling pose, gentle yawn, cape gathering around the body, visibly transitioning into rest.
- `02-docked-sleep`: very compact seated curl, knees tucked up, cheek on folded hands, eyes closed, cape acting like a blanket, tiny blue sleep bubbles.
- `03-tap-to-wake`: still seated and compact, rubbing one eye, the other eye opening, small surprise marks, clearly responding to a tap.
- `04-awake-stretch`: seated low, cheerful eyes closed, both arms stretching overhead, tiny warm sparkles, ready to resume normal activity.

Generation mode: built-in ImageGen using approved Miko reference images, with transparent output enabled.
