Use it from anywhere

curl · fetch · node

Drop these straight into lnch.in, an automation, a status page, or a homepage card. CORS is open and the JSON envelope is stable.

curl 
curl -s https://abhnv.in/api/summary | jq
curl -s "https://abhnv.in/api/search?q=cloudflare" | jq
curl -s https://abhnv.in/api/health | jq
fetch (browser) 
const res = await fetch("https://abhnv.in/api/links");
const { ok, data, meta } = await res.json();
if (!ok) throw new Error("API returned an error");
console.log(`Got ${data.all.length} public links, version ${meta.version}`);
command (lnch.in style) 
// Single command surface — pick by name
const cmd = "cloudflare"; // or summary, links, tags, search, assets, health
const url = `https://abhnv.in/api/command?cmd=${cmd}`;
const { ok, data } = await fetch(url).then(r => r.json());
node 18+ (no deps) 
// Cloudflare Pages local smoke check
// Run the site with: wrangler pages dev . --ip 127.0.0.1 --port 8788
const res = await fetch("http://127.0.0.1:8788/api/cloudflare");
const json = await res.json();
console.log(JSON.stringify(json, null, 2));
Response Shape

A predictable envelope

Success

{
  "ok": true,
  "data": <payload>,
  "meta": {
    "version": "1.0.0",
    "build": "2026-05-07",
    "generatedAt": "2026-05-07T10:21:08.000Z",
    "source": "abhnv.in/api",
    "docs": "https://abhnv.in/api.html",
    "cmd": "profile"
  }
}

Error

{
  "ok": false,
  "error": "Unknown command \"foo\".",
  "hint": "Available: profile, skills, projects, ...",
  "meta": {
    "version": "1.0.0",
    "generatedAt": "2026-05-07T10:21:08.000Z",
    "cmd": "foo",
    "commands": ["profile", "skills", "..."]
  }
}
Why this exists

One source of truth
for every Abhinav project

01

lnch.in friendly

Project launchers, link pages, and personal dashboards can render the same projects, links, and credentials without copy-pasting JSON.

02

One data file

The site, the API, and external consumers all read from the same portfolio data shape. Update once, ship everywhere.

03

Edge-cached

Pages Functions cache JSON at the edge with stale-while-revalidate, so external embeds stay fast and resilient.

04

Open by default

CORS open. Read-only. Zero auth needed for public data. Future writes (forms, webhooks) will live behind their own auth.
